# Owner review console

The owner can watch stored rejected workprints and listen to stored audio candidates
without approving them, retrying production, or uploading anything to YouTube.
`/studio/history?status=previews` retains older attempts with playable media even
when a newer retry has no file. Search and video/audio filters are server-side;
duplicate entries are collapsed only for the same media identity.

`GET`/`HEAD /studio/job/{task_id}/preview-media` authenticates the Studio owner
before reading the job or storage. Rejected workprints retain the existing
object-bound, ranged streaming checks. Final videos and unapproved audio candidates
use validated stored object keys and bounded size/type checks, then a fresh
five-minute playback link. Expired links in old job records are not rewritten.
No media is generated by browsing. List players load on demand; a detail status
poll preserves an existing player and its playback position.

The dashboard shows the last completed worker scheduling check, separately from
each channel's schedule and current-profile next-series preparation state.
The Celery post-run observer writes only an expiring status/timestamp to
`youtube_studio:operations:v1:last_production_tick`; views read it. A signal older
than three minutes is stale. The signal is not evidence of video quality, API
funding, a healthy provider, or successful publication. Its absence or write failure
never authorizes, retries, or suppresses production.

Publication, OAuth, current upload reconciliation and financial controls remain
the existing authorities. Viewing a rejected file grants no publishing permission.
The console does not buy credits or renew an Abacus entitlement.

An observed quality hold hides retry and voice-replacement actions for that
sealed attempt, including a held retry child. The detail page and status poll
keep the owner preview and link to the current production plan. A single bounded
read decorates loaded records in memory; held jobs are never rewritten for
presentation. This observation grants no retry, spending or publication authority;
the existing backend fences remain authoritative if an observation fails.
