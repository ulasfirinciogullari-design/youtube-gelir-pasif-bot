# Queued research continuation

The worker's paid-slot Lua update encodes the three-minute duration `3.0` as
`3`. New queue dispatches use an integer. The original dispatch hash stays
unchanged: authorization and publication accept only that exact equivalent
encoding for an otherwise identical three-minute landscape specification.

A queued root that failed in research before its first provider request may
receive one durable child. Admission requires its exact terminal SpendBlocked
trace, untouched media budget, absent media/publication artifacts, zero native
reasoning, included-router, voice or cash reservations, current channel/profile,
and every preceding episode's public completion. Source access and funding are
checked before reserving the continuation. Duplicate or uncertain queue sends
remain claimed. The worker validates the claim again, then performs normal fresh
research, story, speech, visual and publication checks. Prior jobs, dispatches
and provider records are preserved. A failed critic or unknown request never
qualifies for this continuation.

Two official Sony historical pages have a private source cache because direct
Railway requests return 403 while the existing VPS receives their public bodies.
`ops/refresh_historical_sources.py` retrieves only those exact HTTPS URLs with
the normal bounded public-source reader, then installs them using authenticated
server operations. Every snapshot keeps its full-body hash and actual retrieval
date; later snapshots do not replace older records. Only the latest observation
can be selected, and it expires for research after 72 hours. The VPS refresh runs
every 12 hours under an overlap lock. No public ingestion endpoint exists.

Direct reads remain preferred. Fallback material carries its original date into
the story prompt and still undergoes independent sentence/source review. A cache
hit supplies evidence, never approval, a current-fact claim, or a media allowance.
